# IntelliGroup Ballot Pro

Система распознавания отсканированных бюллетеней для голосования на базе искусственного интеллекта (Google Gemini Vision). 
Приложение извлекает данные из скан-копий, определяет выбор ("ЗА", "ПРОТИВ", "ВОЗДЕРЖАЛСЯ") и структурирует информацию для дальнейшего анализа.

## 🚀 Начало работы (Руководство пользователя)

Данное руководство поможет вам начать работу с приложением после того, как оно было развернуто администратором.

### 1. Настройка API-ключа
Первое, что необходимо сделать при входе в приложение — это настроить подключение к нейросети Google Gemini (доступ предоставляется по выделенному API-ключу).

1. Нажмите на кнопку **"Настройки API Gemini"** (иконка шестеренки) в правом верхнем углу интерфейса.
2. В появившемся окне введите ваш личный API-ключ.
   > **Важно:** Ключ не передается на наши серверы и сохраняется исключительно в локальном хранилище вашего браузера (`localStorage`).
3. *(Опционально)* Если вы используете сторонние сервисы-агрегаторы ключей (например, **ProxyAPI**, **Bothub**, **VseGPT**) вместо прямого подключения к Google, введите **адрес агрегатора (Base URL)** в соответствующее поле. Если вы используете прямое подключение (рекомендуется) — оставьте поле Base URL со значением по умолчанию.
   > 💰 **Ориентировочная стоимость (при работе через агрегаторы):** около **0.2 - 1 руб.** за распознавание 1 страницы бюллетеня. Точная цена зависит от тарифов выбранного агрегатора на Google Gemini Pro и фактического размера загружаемой картинки (количества токенов). При прямом подключении от Google (через AI Studio) действуют щедрые бесплатные лимиты.
4. Нажмите **"Проверить подключение"**. Если ключ действителен и доступен, система подтвердит успешное подключение зеленой галочкой.
5. Нажмите **"Сохранить"**.

> Вы можете получить бесплатный ключ API по ссылке: [Google AI Studio](https://aistudio.google.com/apikey).

### 2. Загрузка бюллетеней
Приложение поддерживает файлы форматов `PDF`, `PNG`, `JPG`, `JPEG`. Вы можете загружать как отдельные страницы, так и многостраничные PDF-документы.

1. Убедитесь, что вы находитесь на вкладке **"Загрузка"**.
2. Перетащите файлы со сканами бюллетеней в обозначенную область или кликните по ней, чтобы выбрать файлы через проводник.
3. Дождитесь завершения обработки:
   - Приложение извлечет каждую страницу из документов.
   - Нейросеть проанализирует данные на страницах, найдет QR-код для группировки листов (если бюллетень многостраничный), а также извлечет выбранные ответы.
4. По окончании процесса система сообщит об успешном распознавании и предложит перейти к проверке.

### 3. Проверка результатов
Так как ИИ может допускать погрешности, обязательно проверяйте результаты!

1. Перейдите на вкладку **"Проверка"**.
2. Слева отображается список всех загруженных бюллетеней (каждый может состоять из нескольких страниц).
3. При выборе бюллетеня слева, в правой части окна появится:
   - **Оригинальные изображения** страниц (для сверки глазами). Картинки можно приближать и листать.
   - **Извлеченные данные**: ФИО, номер помещения, площадь, СНИЛС, размер доли и так далее.
   - **Голосование по вопросам**: список вопросов и определенные голоса ("ЗА", "ПРОТИВ", "ВОЗДЕРЖАЛСЯ", либо пусто, если не распознано).
4. Если вы заметили ошибку распознавания (например, галочка распознана неверно), **вы можете отредактировать** данные прямо в этой панели.
5. После того как вы убедились в корректности данных, нажмите кнопку **"Подтвердить данные"** (зеленая галочка) в верхней части панели проверки. Бюллетень получит статус "Проверено".

### 4. Экспорт данных
После того как бюллетени проверены (желательно), результаты можно выгрузить в удобном виде.

1. Перейдите на вкладку **"Экспорт"**.
2. Убедитесь, что статистика в верхней панели совпадает с ожидаемым количеством проверенных бюллетеней.
3. Вы можете скачать два вида отчетов:
   - **Excel-таблица (`.xlsx`)**: содержит структурированную базу данных всех ответов участников голосования, удобную для сортировки и фильтрации.
   - **Сводный PDF-отчет**: удобочитаемый документ с итогами и разбивки по каждому бюллетеню.

## 🚀 Простой запуск для пользователей (Windows)

Для того чтобы максимально просто запустить приложение на вашем компьютере:

1. Убедитесь, что у вас установлен **Node.js** (скачать можно с [nodejs.org](https://nodejs.org/)).
2. Откройте папку с проектом.
3. Дважды кликните по файлу **`start.bat`**.
4. Скрипт автоматически проверит зависимости, установит их при необходимости, запустит сервер и откроет приложение в вашем браузере.

   > **Внимание:** Не закрывайте черное окно командной строки, пока вы работаете с приложением. При закрытии окна сервер будет остановлен.

## 🛠 Техническая информация для разработчиков

Стек технологий: Next.js (App Router), React, Tailwind CSS, shadcn/ui.

**Запуск проекта локально:**
```bash
# Установка зависимостей
pnpm install

# Запуск в режиме разработки
pnpm dev
```
Откройте `http://localhost:3000` в браузере.

Для сборки в Production используйте `pnpm build` и `pnpm start`. Подробнее см. внутреннюю документацию по развертыванию.
